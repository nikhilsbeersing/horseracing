Tipster Challenge — House Rules

Rules governing points allocation, Tote odds, dead-heat calculations, jockey allowances, and deadline lock procedures.

Please read: what this is (and isn't)

This is a free, private prediction game for a closed group of friends. The 5,000 "points" are notional only — they have no cash value, cannot be bought or cashed out, and are not redeemable for money or anything of value. No entry fee is charged and no real wagers are placed. This site is not operated, endorsed, or licensed by any turf club, racing authority, or gambling regulator, and it is not a gaming service. See the full below for details.

5,000 Points Bankroll & Auto-Save

For every race meeting, tipsters get exactly 5,000 virtual points to allocate. Mandatory min quantity is 100 points per race. Every selection auto-saves instantly.

Weights & Jockey Allowances

Carried weights and jockey claims (e.g. 57.5kg -4kg allowance) are displayed explicitly in racecards and jockey analytics.

Tote Odds & Dead Heats

Points returned = Quantity × Final Tote Odds. In a Dead Heat, returns are split equally between winning selections.

Optional Doubles & Trebles

Doubles and Trebles are 100% optional (min 100 pts if played). Standings track separate statistics for Singles, Doubles, and Trebles.

1-Minute Before Race 1 Lock:

Selections lock automatically 1 minute before Race 1 kickoff. Once locked, no predictions can be edited, and picks become visible to all tipsters.

Terms & Conditions

By creating an account or using this site, you agree to the following.

1. What this is

This is a free, private prediction game built for a closed circle of friends to compare horse racing picks against each other for fun. It is a social leaderboard, not a gambling product.

2. No real money

The 5,000-point balance issued per meeting is entirely notional. Points cannot be purchased, deposited, withdrawn, cashed out, transferred, or exchanged for money, goods, or any prize of value. No entry fee is ever charged.

Correct single picks score Quantity × Final Tote Odds. Optional Doubles/Trebles multiply the odds of each correct leg. Dead-heat winners split returns equally. Incorrect or unsettled picks score zero.

Shared Supabase Database

This app is wired directly to a shared Supabase project — the same one your football tipster site uses — so it connects automatically on every device with no setup step. Accounts live in a shared profiles table, and nothing is cached in this browser: every visit and every save goes straight to the cloud.

To point this app at a different Supabase project, edit the SUPABASE_URL and SUPABASE_ANON_KEY constants near the top of the JavaScript in this file.

One-Time Setup SQL

Already run once for this project — kept here only for reference (e.g. if you ever set up a fresh Supabase project). Safe to re-run any time; it uses if not exists.

create table if not exists profiles (
  username text primary key,
  display_name text not null,
  pin_hash text not null,
  role text not null default 'tipster' check (role in ('tipster','admin')),
  approved boolean not null default false,
  created_at timestamptz not null default now()
);
alter table profiles enable row level security;
create policy "Shared read access" on profiles for select using (true);
create policy "Shared insert access" on profiles for insert with check (true);
create policy "Shared update access" on profiles for update using (true);
create policy "Shared delete access" on profiles for delete using (true);

create table if not exists app_state (
  id text primary key,
  data jsonb not null,
  updated_at timestamptz default now()
);
alter table app_state enable row level security;
create policy "Read app_state" on app_state for select using (true);
create policy "Insert app_state" on app_state for insert with check (true);
create policy "Update app_state" on app_state for update using (true);

These open policies let anyone holding the anon key read/write this data — fine for a private friend league where the key isn't published, but not a substitute for real auth. Races/predictions stay in app_state (one row per site); only profiles is shared between your two sites.
